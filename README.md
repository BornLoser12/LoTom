## スペック
- ファームウェア
  - ZMK を使用しています
  - ZMKStudio に対応しております
- ハードウェア
  - 48 キー
  - choc v2、lofree 系列のスイッチが使用可能
  - 左手側が central,右手側が peripheral になります
  - 両手に OLED 内蔵
  - 左手にのサイドにスライドロータリーを２つ内蔵
    - デフォルトでは左がマウススクロール、下側がタブ切り替えになっております
  - トラックボール19mm
    - ケースごとマグネットで張り付いているので、脱着可能です
  - バッテリー対応 2 つ必要です
    - 横 25mm,縦 35mm,厚さ 5mm 以内のものを使用してください
    - 250mAh で大体 5日は持ちます(1 日 5 時間使用くらい)
    - リチウムイオンバッテリーは十分注意して取り扱ってください(https://www.baj.or.jp/battery/safety/safety16.html)
    - 市販のバッテリーの極性が個体によって異なる例が確認されておりますので、極性には気をつけてご利用ください。tomkey では赤色を+極として作成しております
    - 確認済み対応バッテリーの販売リンク(https://amzn.asia/d/brotpZW)

## 電源および充電について
※ご自身で購入したバッテリーによっては極性が逆になっている可能性がありますので、十分にご確認の上で接続をお願いいたします！(表記と端子が逆の事例もありました)
- スイッチを ON にしている状態で USB に接続することで充電されます。充電しながらの使用も可能です
- スイッチが OFF の状態で USB を接続すると USB からの給電で使用できますが、OFF の状態ではバッテリーに充電はされません
  - 安全上意図的にバッテリー ON 状態でないと充電されない仕様になっております
- バッテリー残量に関しては oled 上に表示されるようになっております
  - 上側が左手のバッテリー残量
  - 下側が右手のバッテリー残量

## oled の切り替えについて

- キーマップは手元の Cygnus-S ソースの Windows 用設定を LoTom に移植しています。
- OLED は以下を `n` にして Windows 用の修飾キー表示に設定しています。
- config/boards/shields/lotom/lotom_L.conf
- `CONFIG_ZMK_TOM_OLED_MAC_MODIFIERS=n`にする
- OLED の表示設定と、実際に送るキーの設定は別です。

### キー位置とレイヤー

- 比較元は `BornLoser12/Cygnus-S` の現在のソースです。9月5日の Studio 保存データとは別です。
- 各手の文字キーは外側から小指1列・薬指1列・中指1列・人差し指3列に対応します。
- Cygnus にある内側のスクリーンショット・Ctrl・Esc・Tabと親指キーは、対応する位置に残しています。
- Cygnus にない5キーは全レイヤーで未割り当てです。位置番号（0始まり）は `0, 1, 7, 8, 46`：最上部の左右2キー、QWERTY段の内側左右2キー、最下段の右外側から2番目のキーです。
- 同時押しコンボは `I+O` → Gesture、`L+マイナス` → Precision の2つだけです。Base/Mouseレイヤーで有効、判定時間は50ms、押している間だけ切り替わります。クリック等のコンボは追加していません。
- キーコードは Cygnus の設定を保持しています。記号や変換・無変換の動作は PC 側の配列・IME設定にも依存します。

| レイヤー | 内容 | 入り方 |
| --- | --- | --- |
| 0 Base | 通常入力 | 通常時 |
| 1 Function | Fキー・テンキー | 左親指の無変換キーを長押し |
| 2 Symbols | 記号・ショートカット | 右親指のEnterを長押し |
| 3 Arrow | 矢印・Windows操作・接続設定 | 右親指の変換キーを長押し |
| 4 Mouse | クリック・戻る・進む | トラックボール操作、またはLキーを長押し |
| 5 Scroll | トラックボールでスクロール | マイナスキーを長押し |
| 6 Utility | Bluetooth・Studio・ブートローダー等 | Arrow中にA位置を長押し |
| 7 Precision | ポインター移動量を1/5にする | Lとマイナスを同時押し |
| 8 Gesture | トラックボールの方向でWin＋矢印を送る | IとOを同時押し |

- 長押し判定は Cygnus と同じ balanced / 200ms です。
- オートマウスは無操作60,000msで解除します。通常キー入力などによる解除条件は既存の runtime input processor に従います。
- スクロールは Cygnus と同じ倍率 `1/60`、縦方向固定・閾値 `200` です。
- ジェスチャー処理は Cygnus から移植し、感度 `tick=133`、連続入力間隔 `120ms`、押下時間 `35ms` を使用します。右側のトラックボール入力を左側centralで処理します。
- 下側ロータリーはWindows用タブ切り替え：時計回り `Ctrl+PageUp`、反時計回り `Ctrl+PageDown`。
- 側面ロータリーは通常スクロール、Arrowでは Cygnus と同じタブ切り替えです。
- トラックボールのCPIはLotom既存の600です。ハードウェア定義・左右通信・DYA Studio対応は既存のものを使用します。

### 書き込み後の設定確認

- Studioで保存済みのキーマップや入力処理設定がある場合、ファームウェアを書き換えても保存値が優先されることがあります。
- その場合は先に現在の設定を保存し、Studio側で今回のキーマップと入力処理の設定を反映してください。特にマウスL4・スクロールL5・解除時間60,000msを確認してください。
- キーマップ、左右の入力処理、OLED表示を確認してから使用してください。Bluetoothペアリングを含む全設定リセットは、この変更の必須手順ではありません。
